# Hip-and-knee-implant-design-
Hip and Knee Implant Design
Project Overview:This project focuses on CAD modelling, design customization, and 3D printing of hip and knee implant prototypes as part of a Biomedical Engineering project.

Objectives:Design 3D models of hip and knee implant components.
Explore implant customization using CAD software.
Export CAD models into STL format.
Prepare models for 3D printing using slicing software.
Document the design and prototyping workflow.

Tools and Technologies:CATIA V5,STL and STEP file formats,3D printing and slicing software,PLA polymer for prototype development

Project Progress:
CAD modelling of implant components
Component identification and assembly
STL file preparation
Slicing and print preparation
